# Journal UX

## Structural rules applied
- **Active Voice Protocol:** Passive structures such as "Not to be confused with..." were refactored into direct commands ("Do not confuse this with...") and "The best code is the code never written" to "The best code is the code you never write" to assert navigation control and immediate clarity.
- **Lexicon Consistency:** Adjusted mismatched plurals (flag -> flags, entry -> entries, server -> servers) in a list to enforce grammatical parallel structure and elevate the polish of the text.
- **Direct Referencing:** Changed "The `AGENTS.md` here is..." to "This `AGENTS.md` is..." avoiding clunky phrasing.
